# Fotos do site

Coloque as fotos nesta pasta com os nomes abaixo (jpg, jpeg, png ou webp). O site usa a foto
automaticamente; enquanto o arquivo não existir, o bloco aparece sem foto.

| Nome do arquivo | Onde aparece |
|---|---|
| `hero` | Fundo do topo da página inicial e das páginas de cidade |
| `equipe` | Seção "Por que a SOS" |
| `desentupimento-de-pia` | Card e página do serviço |
| `desentupimento-de-ralo` | idem |
| `desentupimento-de-vaso-sanitario` | idem |
| `desentupimento-de-cano` | idem |
| `desentupimento-de-esgoto` | idem |
| `desentupimento-de-coluna` | idem |
| `desentupimento-de-rede-pluvial` | idem |
| `limpeza-de-caixa-de-gordura` | idem |
| `hidrojateamento` | idem |

A logo vai em `src/assets/logo-sos.png` (uma pasta acima).

Atenção: nenhuma foto pode mostrar telefone diferente do da praça (ex.: 0800 em uniforme ou
carro) nem citar serviço que a SOS não oferece no site.
